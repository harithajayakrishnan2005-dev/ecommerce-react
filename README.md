E-Commerce Website (React)
A responsive e-commerce website built with React.js. Users can browse products, view product details, add items to a cart and move through the shopping flow.

Features
Product listing and product details pages
Shopping cart
Wishlist
Login and registration pages
User profile
Order and payment pages
About and contact pages
Responsive, interactive UI components
Tech Stack
React.js
React Router
Fetch API
HTML, CSS, JavaScript
Project Structure
src/
  components/   Navbar, Footer, ProductCard
  pages/        Home, Products, ProductDetails, Cart, Wishlist,
                Login, Register, Profile, Order, Payment, About, Contact
  styles/       CSS files for each page and component
Getting Started
Clone the repository
git clone https://github.com/harithajayakrishnan2005-dev/ecommerce-react.git
Go to the project folder
cd ecommerce-react
Install dependencies
npm install
Start the app
npm start
The app opens at http://localhost:3000.
